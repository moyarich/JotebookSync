# JotebookSync example

Open `sales-analysis.py` in VS Code and run **JotebookSync: Set Up or Update
Paired Files**. Select the formats you want to keep synchronized, then save the
form.

The script uses Jupytext's `percent` cell markers:

- `# %% [markdown]` starts a Markdown cell.
- `# %%` starts a code cell.

After pairing, edit either representation and use **Review Pair Freshness** to
inspect changes before synchronizing the pair.
