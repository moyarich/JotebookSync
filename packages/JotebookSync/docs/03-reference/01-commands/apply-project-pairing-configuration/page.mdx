# Apply Project Pairing Configuration…

In the Command Palette, run **JotebookSync: Apply Project Pairing Configuration…**.

Select the project folder or its `jupytext.toml` or `pyproject.toml`. Review the notebook count and confirm to create or sync paired representations according to the configuration.
