# Run Advanced Jupytext Command…

In the Command Palette, run **JotebookSync: Run Advanced Jupytext Command…**.

Enter Jupytext arguments as a JSON array, such as `["--version"]`. Review and confirm the arguments. JotebookSync adds Python and `-m jupytext` automatically.
