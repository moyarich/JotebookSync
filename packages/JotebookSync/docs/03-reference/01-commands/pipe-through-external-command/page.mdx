# Pipe Through External Command…

In the Command Palette, run **JotebookSync: Pipe Through External Command…**.

Enter a command and an optional pipe format. Use `{}` where the command expects a temporary filename. Confirm the command, then choose whether to update only the current file or synchronize the pair.
