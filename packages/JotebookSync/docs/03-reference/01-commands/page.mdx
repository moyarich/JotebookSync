# Commands

JotebookSync commands are available from the Command Palette. Context-appropriate commands also appear in Explorer, the Paired Files view, and the notebook toolbar.

## Pairing and navigation

- **Open Paired Notebook**
- **Configure Paired Files…**
- **Remove Pairing…**
- **Remove File from Pair…**
- **Show Paired Files**
- **Refresh Paired Files**

## Synchronization and review

- **Overwrite Paired Files from This File…**
- **Sync All from Newest Paired File…**
- **Review Pair Freshness…**

## Conversion and notebooks

- **Convert File to Another Format…**
- **Create Notebook from Text File…**
- **Update Existing Notebook from Text File…**

The update command preserves saved notebook outputs while replacing notebook inputs and metadata from the selected text representation.

## Project configuration

- **Create Project Pairing Configuration…**
- **Apply Project Pairing Configuration…**

## Format discovery

- **Show Available Formats**
- **Refresh Available Formats**

## Validation and formatting

- **Format with Black**
- **Test Round-Trip Conversion…**
- **Test Strict Round-Trip Conversion…**

## Advanced Jupytext workflows

- **Pipe Through External Command…**
- **Check with External Command…**
- **Set Notebook Kernel…**
- **Execute Notebook…**
- **Update Notebook Metadata…**
- **Set Format Options…**
- **Run Pre-commit Workflow…**
- **Run Advanced Jupytext Command…**

Some advanced commands can execute external programs or notebook code. JotebookSync asks for confirmation where appropriate.
