# Run Pre-commit Workflow…

In the Command Palette, run **JotebookSync: Run Pre-commit Workflow…**.

Stage your notebook changes in Git and choose a pre-commit mode. Optionally limit the source format, then confirm to synchronize matching staged notebooks.
