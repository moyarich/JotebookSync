# Test Strict Round-Trip Conversion…

In the Command Palette, run **JotebookSync: Test Strict Round-Trip Conversion…**.

Open the source file and choose a target format. The strict check uses Jupytext’s stricter comparison to catch differences that the standard round-trip check may accept.
