## Repository layout

```text
src/            VS Code extension runtime
webviews-ui/    React/Vite webview UI
test/           extension and webview tests
demo/           demo and README GIF tooling
media/          extension icons and README media
docs/           user and developer documentation
scripts/        development and publishing helpers
```

The extension runtime and webview UI are built separately and packaged together
for the VS Code extension.

## Common commands

```sh
npm install
npm run compile
npm run watch
npm test
npm run lint
npm run package
```
